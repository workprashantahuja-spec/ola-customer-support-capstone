# GitHub publishing checklist

1. Sign in to GitHub in your browser.
2. Create a new **public** repository named `ola-customer-support-capstone`.
3. Do not add a README, `.gitignore`, or license on GitHub; this folder already contains the project files.
4. Copy the repository URL after GitHub creates it.
5. We will connect this prepared local repository to that URL, make the first commit under your GitHub identity, push it, and check the public link.

Before publishing, read `README.md` and `BUSINESS-WALKTHROUGH.md`. The repository must be presented accurately as a fictional, local demonstration.
